# Goldammerweg

The concrete setup this repository is developed against: a KitchenTab on the wall, five
people, calendars split across CalDAV and `local_calendar`, and shopping lists in Bring!.

Use it as a worked example — the entity ids are specific to this household.

### Shared calendars and lists

- **Family calendars:** `calendar.familien_kalender_dill`, `calendar.familie_intern`,
  `calendar.allgemeiner_kalender`
- **Family lists:** `todo.familie`, `todo.familien_erinnerungen`, `todo.erinnerungen`,
  `todo.nachbarn`
- **Read-only calendars:** `calendar.deutschland_by`, `calendar.workday_sensor_kalender`

Read-only matters: those two are generated by integrations and cannot take new events.
Listing them here keeps them visible on the board but out of the create sheet, so a tap
on a public holiday cannot fail with a write error.

## Dashboard

`dashboard-hearth.yaml` — paste into a new dashboard's **Raw configuration editor**.

Three views: **Board** (header, people, month calendar, agenda), **Listen** (Bring! and
family lists), **Aufgaben & Punkte** (Chores4Kids).

Optional HACS cards referenced there: `trash-card` and `chores4kids-card`. Delete those
two cards if you do not use them — everything else is Hearth's own.

## KitchenTab

The tablet is pointed at a dashboard through `input_text.kitchentab_home_url`. Switch it
to the Hearth board by setting that helper to the new dashboard's URL, for example
`http://192.168.179.1:8123/hearth-board/board`.

The existing *UI - WallPanel profile switch (KitchenTab)* automation and
`input_text.kitchentab_wallpanel_profile` keep working unchanged — WallPanel's screensaver
still provides the photo-frame mode, and `kiosk-mode` still hides the header and sidebar.
Hearth adds no kiosk handling of its own; it deliberately leaves those to the components
already doing the job.

### Touch sizing

Cards target at least 44px for anything tappable. If the tablet's browser is scaled, check
the month grid first — day cells collapse before anything else does, and
`max_events_per_day` is the dial to turn.
